# 국가근로 근무표

국가근로 장학생이 월 근로시간을 달력으로 관리하는 모바일 웹 앱입니다. 설치 없이 휴대폰 브라우저로 열고, 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

## 기능
- 교내·교외 근로 선택, 시급 자동 적용(`wages.json`)
- 요일별 근무 시간대(하루 여러 구간), 근무 기간(방학 제외)
- 달력에 날짜별 근무시간, 공휴일·대체공휴일 자동 제외(2026–2027)
- 1시간 단위 휴가, 학교 휴무일 직접 지정
- 월 배정 시간 초과 시 팝업과 추천 휴가

## 파일
| 파일 | 내용 |
| --- | --- |
| `index.html` | 앱 전체(HTML·CSS·JS) |
| `wages.json` | 연도별 교내·교외 시급표. 한국장학재단 공지 기준으로 갱신 |
| `manifest.webmanifest`, `icon*` | 홈 화면 추가용 |
| `sw.js` | 오프라인 지원 |

## 시급 갱신
`wages.json`의 `wages`에 연도를 추가하면 앱이 그 해부터 새 시급을 씁니다. 새해 시급이 없으면 직전 연도 값으로 계산합니다.

## 배포
GitHub Pages(브랜치 `main`, 폴더 `/`)로 배포합니다. 데이터는 각 사용자 브라우저(localStorage)에만 저장됩니다.
